# 泰来才 · 易学小程序

微信小程序版本，基于 [yixue-tailaicai](https://github.com/TaiLaiCai/yixue-tailaicai) Web 版本改写。

**AppID**: `wxe04efc2bd532a51a`
**分支**: `miniprogram`

---

## 功能模块

| 模块 | 说明 |
|------|------|
| **易学知识** | 易经导论、五行八卦、天干地支静态知识库 |
| **六十四卦** | 六十四卦卦名、卦象、卦辞查阅 |
| **卦象演练** | 铜钱起卦 / 时间起卦 / 数字起卦，展示卦象结构 |
| **紫微斗数** | 十二宫、十四主星、四化系统学术百科 |

---

## 目录结构

```
pages/
├── intro/        启动引导页
├── knowledge/    易学知识（三标签：易经 / 五行 / 天干地支）
├── hexagrams/    六十四卦
├── divination/   卦象演练
└── ziwei/        紫微斗数学术百科
utils/
├── constants.js  星曜、宫位、四化等常量
├── ziwei.js      紫微斗数排盘算法（仅用于计算结构）
└── divination.js 易经起卦算法
```

---

## 开发环境

- 微信开发者工具
- 基础库 >= 3.0.0
- 无第三方依赖，纯原生小程序

---

## 合规说明

本小程序内容定位为**传统文化学习与学术研究**：

- 紫微斗数页为静态百科，不生成个性化命盘
- 卦象演练仅展示卦象结构，不提供吉凶判断与时间预测
- 所有内容均基于古籍文献整理，并附免责声明

---

## 本地运行

1. 克隆仓库，切换到 `miniprogram` 分支
2. 用微信开发者工具打开本目录
3. 填入 AppID 或使用测试号预览
