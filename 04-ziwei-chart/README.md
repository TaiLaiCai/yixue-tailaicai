# 04 · 紫微斗数命盘

基于**倪海夏推演法**的紫微斗数在线排盘。输入农历生日和时辰，自动生成 4×4 十二宫命盘，并附带命宫解析、三方四正、四化解盘、易经卦象关联。

**预览：** 直接打开 `demo.html`

---

## 功能清单

| 功能 | 说明 |
|------|------|
| 十二宫排盘 | 4×4 网格，命宫金色高亮，中央格显示命局 |
| 主星安星 | 紫微系6星 + 天府系8星，按倪海夏法排列 |
| 辅星安星 | 天魁、天钺、文昌、文曲、左辅、右弼、禄存 |
| 四化标注 | 化禄/化权/化科/化忌，色码区分 |
| 大限标注 | 每宫显示对应岁数段（顺/逆布） |
| 宫位弹窗 | 点击任意宫格，弹出详细解析 |
| 命宫解析 | 主星性格、倪师论命要点 |
| 易经关联 | 每颗主星对应一卦，给出卦象启示 |

## 算法说明

### 命宫位置（`mg` 函数）
```js
// 命宫地支 = (1 + 农历月 - 出生时辰 + 120) % 12
function mg(month, hour) {
  return (1 + month - hour + 120) % 12;
}
```

### 五行局（`getNJ` 函数）
根据命宫天干（`pg` 函数计算）和地支查表得出：
- 水二局、木三局、金四局、土五局、火六局

### 主星安星（`msp` 函数）
```js
// 先定紫微星位置 (zwp)，再依序推算其余13颗主星
function msp(day, ju) {
  const zw = zwp(day, ju);     // 紫微位置
  const tf = tfp(zw);          // 天府位置（与紫微对宫）
  // 紫微系：zw, zw-1, zw-3, zw-4, zw-5, zw-8
  // 天府系：tf, tf+1, tf+2, tf+3, tf+4, tf+5, tf+6, tf+10
  return [ ...紫微系位置, ...天府系位置 ];
}
```

### 四化（`SH` 数组）
```js
// SH[天干索引] = [化禄主星索引, 化权主星索引, 化科主星索引, 化忌主星索引]
const SH = [
  [5,13,3,2],   // 甲年：廉贞禄，破军权，武曲科，太阳忌
  [1,11,0,7],   // 乙年：天机禄，天梁权，紫微科，太阴忌
  // ...
];
```

## 关键数据结构

```js
// 每宫格数据对象
{
  p:    地支索引 (0-11),
  pi:   宫名索引 (0-11, 以命宫为0),
  pgn:  宫干索引 (0-9),
  msi:  主星索引数组,
  msn:  主星名字数组,
  axH:  辅星数组 [{n:'天魁', c:'ax'}],
  hH:   四化数组 [{l:'化禄', c:'hl', s:'廉贞'}],
  dxs:  大限起始岁数,
  im:   是否命宫 (boolean),
  is:   是否身宫 (boolean)
}
```

## 倪海夏论命核心原则

1. **命宫定格局**：主星决定人格底色，辅星锦上添花
2. **三方四正**：命/财/官/迁四宫联动，是命局的核心骨架
3. **化忌不是凶**：化忌是"执念"所在，代表最在意的地方，也是成长突破口
4. **空宫不空**：无主星的宫位参看对宫，对宫主星以及飞化入命都算
5. **大限流年**：时间维度比命盘本身更重要，时机对了事情自然成
